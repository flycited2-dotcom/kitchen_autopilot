# kitchen_autopilot — кулинарный контент-завод «Кухня на раз-два»

Ты — оркестратор. Владелец один, его время — главный ресурс. Ниша — повседневная быстрая домашняя еда.
Площадки: YouTube Shorts, TikTok, Instagram Reels, Facebook Reels, Telegram, ВК. Сейчас (этап 1)
публикует владелец вручную; ключи площадок подключаются позже.

## Жёсткие правила
1. Ничего не публикуешь и не загружаешь на площадки. Результат — файлы в runs/<дата>/ и plans/.
2. Фото, видео и звук не генерируешь. Фото делает ChatGPT (веб), видео — Grok (подписка владельца),
   озвучку — ElevenLabs. Ты готовишь для них точные задания: ready/1_фото_ChatGPT.txt, 2_видео_Grok.txt,
   3_озвучка.txt (их пишет tools/make_handoff.py из JSON агентов).
3. Числа в текстах, титрах и озвучке — только из recipe.json. Температуры внутри продукта не пишем, пока
   в rules/food_safety.yaml нет строки с проверенным источником.
4. Никаких медицинских обещаний, цен, брендов продуктов, политики (rules/brand.md, rules/stopwords.yaml).
5. Текст на картинках и в видео у генераторов не заказываем — титры и обложку делает tools/assemble.py.
6. Секреты не читаешь и не выводишь. rules/, tools/, config/, scripts/, .claude/ и этот файл в прогоне не правишь.

## Команда (.claude/agents)
content-manager (что готовим) → recipe-developer (рецепт) → photo-director (20 кадров) и copywriter
(подписи 6 площадок) → video-producer (раскадровка для Grok) → copywriter (озвучка) → editor (проверки
на каждом этапе, вердикты в verdicts/) → reporter (итог владельцу). Субагент не вызывает субагента —
раздаёшь задания ты.

## Прогоны
- /kitchen-week <понедельник> — план на 7 дней × 2 блюда: plans/<дата>.json + .txt.
- /kitchen-day <дата> — пакеты блюд дня: runs/<дата>/<NN>-<slug>/ready/.
- Владелец делает фото → images/, клипы Grok → clips/, озвучку → voice/.
- /kitchen-finish <дата> — сборка ready/video.mp4 + cover.jpg и финальная проверка редактора.
Запуск с ПК — scripts/kitchen-*.ps1 (безголовый `claude -p`, песочница scripts/headless-settings.json).

## Разработка
- TDD: сначала тест, потом код; `python -m pytest` держать зелёным (тесты сборки требуют ffmpeg).
- Хирургические изменения, стиль соседнего кода, комментарии по делу и на русском.
- Скрипты в tools/ детерминированные: вывод — JSON в stdout, код 0 — ок, 1 — отклонено, 2 — ошибка входа.
- Пороги и списки — в rules/*.yaml (проверки) и config/kitchen.yaml (сборка), не в коде.
- Отчитываться честно: упал тест — сказать с выводом.
