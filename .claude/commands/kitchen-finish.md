Дата: $ARGUMENTS.

Режим запуска — безголовый (`claude -p`): субагентов вызывай синхронно (`run_in_background: false`),
не завершай ход, пока не выполнен шаг 4.

1. Найди папки блюд runs/$ARGUMENTS/*/ с verdicts/package.json, где ok=true.
2. Для каждой: `python tools/assemble.py runs/$ARGUMENTS/<NN>-<slug>`.
   - Код 1 — не хватает файлов (список в выводе, поле missing) или озвучка длиннее ролика: запомни вывод,
     к следующему блюду.
   - Код 2 — ошибка: запомни вывод, к следующему блюду.
   - Код 0 — вызови editor: этап «финал», папка блюда → verdicts/final.json.
3. Вызови reporter: режим «сборка», дата $ARGUMENTS; передай ему выводы assemble по каждому блюду.
4. Последним сообщением выведи содержимое runs/$ARGUMENTS/summary.txt.

Ничего не публикуй.
