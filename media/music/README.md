# Музыка для роликов

Кладите сюда только треки, на которые у вас есть лицензия (купленные стоки, бесплатные библиотеки
с разрешением на коммерческое использование, своя музыка). Популярные песни дают блокировки и снятие
ролика с монетизации.

Форматы: .mp3, .wav, .m4a, .aac, .ogg. Сборка (tools/assemble.py) выбирает трек по id блюда — одно и то же
блюдо при пересборке получает тот же трек. Папка пустая — ролик собирается без музыки.
Сами треки в git не попадают (.gitignore).
