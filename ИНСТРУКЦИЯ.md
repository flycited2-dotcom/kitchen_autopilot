# Инструкция владельца — «Кухня на раз-два»

Всё работает на вашем ПК (Windows). Агенты готовят рецепты, задания для ChatGPT и Grok, текст озвучки и подписи
для 6 площадок. Вы делаете фото, видео и озвучку по готовым заданиям, а ролик собирается и проверяется сам.
Публикуете вы вручную.

## 1. Установка (один раз)

Откройте PowerShell и выполните по очереди:

```powershell
cd $HOME\Documents\GitHub
git clone https://github.com/flycited2-dotcom/kitchen_autopilot
cd kitchen_autopilot
pip install -r requirements.txt
winget install Gyan.FFmpeg
```

Закройте PowerShell и откройте новый (чтобы подхватился FFmpeg), затем проверка:

```powershell
cd $HOME\Documents\GitHub\kitchen_autopilot
ffmpeg -version
python -m pytest
```

Должно быть «passed» без «failed». Claude Code у вас уже установлен — он и запускает агентов.

## 2. Раз в неделю — план

```powershell
powershell -ExecutionPolicy Bypass -File scripts\kitchen-week.ps1
```

Без даты — план на ближайший понедельник. С датой: `... scripts\kitchen-week.ps1 2026-11-02`.
Результат — `plans\2026-11-02.txt` (читать) и `plans\2026-11-02.json` (по нему работает день).
Хотите заменить блюдо — поправьте `.json` или попросите Claude в обычном чате.

## 3. Каждый день — пакеты блюд

```powershell
powershell -ExecutionPolicy Bypass -File scripts\kitchen-day.ps1
```

Без даты — на завтра. Откроется папка дня `runs\2026-11-02\`, в ней по папке на блюдо (`01-...`, `02-...`)
и `summary.txt` — итог. В каждой папке блюда:

```
ready\0_ЧТО_ДЕЛАТЬ.txt     ← начните отсюда
ready\1_фото_ChatGPT.txt   ← стиль + 20 промптов
ready\2_видео_Grok.txt     ← ТЗ ролика + промпт на каждую сцену и какое фото прикрепить
ready\3_озвучка.txt        ← текст для ElevenLabs
ready\4_тексты\            ← YouTube.txt, TikTok.txt, Instagram.txt, Facebook.txt, Telegram.txt, VK.txt
ready\5_рецепт.txt
images\  clips\  voice\    ← сюда кладёте результаты
```

## 4. Фото, видео, озвучка

1. **ChatGPT.** Новый чат → первым сообщением блок СТИЛЬ → затем промпты кадров по одному.
   Картинки сохраняйте в `images` под номерами: `01.png`, `02.png` … (подойдут .jpg и .webp).
2. **Grok.** Для каждой сцены прикрепите указанное фото и вставьте промпт сцены. Клипы сохраняйте в `clips`:
   `01.mp4`, `02.mp4` … Титры и озвучку в Grok не добавляйте — их наложит сборка.
3. **ElevenLabs** — сервис озвучки (не путать с Lovable: тот делает сайты). Вставьте текст из `3_озвучка.txt`, выберите голос по описанию, скачайте и сохраните как
   `voice\voiceover.mp3`. Без озвучки ролик тоже соберётся.
4. Музыка (по желанию): положите лицензированные треки в `media\music\` — сборка подложит тихо под голос.

## 5. Сборка и проверка

```powershell
powershell -ExecutionPolicy Bypass -File scripts\kitchen-finish.ps1 2026-11-02
```

Для каждого блюда получится `ready\video.mp4` (1080×1920, титры, озвучка, музыка) и `ready\cover.jpg`.
Редактор просматривает кадры ролика и пишет вердикт; итог — в конце `runs\2026-11-02\summary.txt`.
Чего-то не хватает (клипа, фото обложки) — в итоге будет список файлов.

## 6. Публикация

Вручную: ролик `ready\video.mp4`, обложка `ready\cover.jpg`, подписи — из `ready\4_тексты\`.
В Telegram — видео с подписью, затем вторым сообщением рецепт (он в том же файле после разделителя).
На площадках, где есть отметка «создано ИИ» (TikTok, YouTube), ставьте её.

## Если что-то пошло не так

- Лог каждого запуска — `logs\` (week-…, day-…, finish-…).
- «не найден ffmpeg» — откройте новое окно PowerShell после установки FFmpeg.
- «не найден шрифт» — впишите путь к .ttf с кириллицей в `config\kitchen.yaml` → `fonts`.
- «озвучка длиннее ролика» — перегенерируйте озвучку чуть быстрее или короче.
- Клип Grok длиннее сцены — сборка обрежет; короче — дотянет последним кадром.
